# LLM selection

## Embedding Model

For retrieval we used the open source embedding model 'Qwen3-Embedding-8B' Which ranks top in **MTEB Retrieval** rankings [https://huggingface.co/spaces/mteb/leaderboard].
The rankings are there in MTEB.csv

## Generating model

For Generating LLMs we are Taking LLMs from **LM Arena text** rankings [https://lmarena.ai/leaderboard/text] as of 8 Sep 2025, as given in screencapture-lmarena-ai-leaderboard-text-2025-09-08-15_27_44.png
